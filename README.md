# Samuel Orth — Portfolio

A holographic-HUD portfolio: 8 featured AI and full-stack projects on a 3D ring, case studies, live demos, and an AI guide that answers questions and drives the view with tool calls.

**Live:** _coming soon_

## Stack
Next.js · TypeScript · React Three Fiber · Tailwind · Zustand · Zod · Vercel AI SDK · Upstash · Resend · Vercel

## Run locally
```bash
pnpm install
cp .env.example .env.local   # fill in values
pnpm dev
```
